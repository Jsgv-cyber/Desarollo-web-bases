Este proyecto corresponde a mi portafolio y hoja de vida personal, desarrollado con HTML y CSS. En él presento mi formación profesional, intereses, metas y una tabla detallada con mis habilidades creativas y técnicas. Además, en la sección inferior de la página se encuentra un botón llamado 'ver todos mis Proyectos', el cual redirige a un directorio con los enlaces hacia los demás entregables del curso, abarcando tanto las maquetaciones web como los trabajos realizados con inteligencia artificial.
